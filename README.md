# OnBajet

Prototype web app for discovering travel deals and planning trips with AI.

## Setup

1. Copy `.env.local.example` to `.env.local` and provide your own values.
2. Install dependencies:
   ```bash
   npm install
   ```

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
npm start
```

## Deploy

Ready to deploy on [Vercel](https://vercel.com). Connect the repository — Vercel auto-detects Next.js and uses `npm run build` by default. No extra configuration needed.
