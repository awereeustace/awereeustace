# OnBajet

Prototype web app for discovering travel deals and planning trips with AI.

## Setup

1. Copy `.env.local.example` to `.env.local` and provide your own values.
2. Install dependencies:
   ```bash
   npm install
   ```

## Development

Run the development server:
```bash
npm run dev
```

## Build

Create a production build and start the server:
```bash
npm run build
npm start
```

## Deploy

This app is ready to deploy on [Vercel](https://vercel.com). Connect the repository and use the default build command `npm run build`.
